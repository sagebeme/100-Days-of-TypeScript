The full syllabus

100 projects in 8 phases. Each phase ends with a capstone that uses everything before it.

Nothing matches that. Try "game", "api" or "M-Pesa".

Set up once, in about ten minutes

  1. Install Node.js 24 or newer from nodejs.org. Check with node --version: older versions can't run .ts files directly.
  2. Get the course: 
    git clone https://github.com/sagebeme/100-Days-of-TypeScript.git
cd 100-Days-of-TypeScript
npm install
  3. Start Day 1: open phase-1-terminal/day-001-gamer-tag, write your code in starter/, and run npm test -- day-001 until it's green.
  4. From Day 30 projects run in the browser: npm run dev -- phase-3-browser/day-030-split-the-bill/starter, then open the address it prints.

Commit your work every day. In three months you'll want to see how far you came.
